# Итоги практики «Детектив»: уроки 1–4

Результаты самостоятельной проверки по реальным файлам (~80% верно).

**Усвоено (можно не повторять):** анатомия файла (namespace, границы класса, перечисление методов), базовые типы включая ловушку `"true"`, чтение сигнатур (вход/выход/видимость), распознавание полей и констант, назначение Page Object («изоляция от тестов» — своими словами).

**Поправлено в ходе разбора:** `char` vs `string` (одинарные кавычки), `=>` как короткий `return`, «каждый `new` = один объект» (путала поля и объекты), смысл `return this` для цепочек.

**Сильный сигнал:** в блоке «найди ошибку» нашла баг `void` + `return this`, который не был задуман — умение сверять сигнатуру с телом развивается хорошо.

**Зоны роста для следующих уроков:** согласованность типа возврата и `return`; считать объекты по `new`; `=>` — повторится в уроке 9. Готова к уроку 5 (условия) — там `bool` и сравнения станут рабочим инструментом.
