# Page Object и селекторы — первое понимание

На самопроверочный вопрос («кнопке поменяли id — какая строка изменится?») ученица верно указала на строку с `const`-селектором, хотя выбрала `LoginField` вместо `SubmitButton`. Сама идея усвоена: селектор — константа наверху файла, правится в одном месте, тесты не трогаем. Осталась неточность «какой именно селектор за что отвечает» — это нормально на этапе урока 1.

**Implications**: Page Object как паттерн можно считать введённым. В следующих уроках подкреплять различие «поле ввода vs кнопка vs сообщение об ошибке» на примерах селекторов. Урок 4 (классы) можно не упрощать — конструктор и readonly поле ей уже встречались вживую.
