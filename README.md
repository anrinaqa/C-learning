# Учебный курс C# для QA

Цель: научиться **читать** код автотестов, находить ошибки и понимать структуру проекта. Писать с нуля — необязательно. Полная цель и критерии — в [MISSION.md](MISSION.md).

## Структура папки

```
c#/
├── MISSION.md           # зачем учимся — вся программа под эту цель
├── NOTES.md             # твои предпочтения обучения
├── RESOURCES.md         # кураторские ссылки (учебники, доки, сообщества)
├── GLOSSARY.md          # словарь терминов (пополняется по ходу)
├── learning-records/    # журнал того, что уже усвоено
│
├── lessons/             # HTML-уроки: короткие, с квизами
│   └── 0001-anatomiya-fayla-csharp.html
├── reference/           # печатные шпаргалки
│   ├── sintaksis-decoder.html    # расшифровка синтаксиса
│   └── chtenie-oshibok.html      # как читать упавший тест
├── assets/              # общие стили и виджет квиза для уроков
│
├── LearningCSharp/      # запускаемые примеры кода к каждому уроку
│   └── Lessons/         # .cs файлы с подробными комментариями
└── TestExample/         # пример реального тестового проекта
    ├── FakeDriver.cs    # имитация браузера
    ├── Pages/           # page objects
    └── Tests/           # тесты xUnit
```

## Как заниматься

1. Открой HTML-урок из `lessons/` в браузере → прочти → пройди квиз.
2. Запусти соответствующий `.cs` пример:
   ```bash
   cd LearningCSharp
   dotnet run    # введи номер урока
   ```
3. Поиграй с примером тестового проекта:
   ```bash
   cd TestExample
   dotnet test
   ```
4. Непонятное — спрашивай Devin в чате.

## План уроков

| # | Тема | Зачем тебе |
|---|------|-----------|
| 1 | Анатомия файла | Открываешь любой .cs и видишь структуру |
| 2 | Переменные и типы | Понимаешь, что за данные в коде |
| 3 | Методы | Читаешь вызовы page.Login(...), Assert.*(...) |
| 4 | Классы и объекты | Page Object'ы, driver, new |
| 5 | Условия | Проверки состояния, логика тестов |
| 6 | Коллекции и циклы | Списки элементов, параметризация |
| 7 | Ошибки | **Читать stack trace упавшего теста** |
| 8 | Async/await | Playwright/REST тесты — сплошь async |
| 9 | Странный синтаксис | =>, ?, ??, <T> — расшифровка |

HTML-уроки создаются по мере прохождения (следующий генерируется, когда освоен текущий — это осознанно: уроки подстраиваются под твой темп).

## Чек-лист "проверяю код от ИИ"

- [ ] Все скобки `{ }` сбалансированы, методы закрыты
- [ ] Нет забытых `await` у async-вызовов (частая причина flaky-тестов)
- [ ] Селекторы соответствуют реальной странице
- [ ] Assert проверяет именно то, что в тест-кейсе (expected/actual)
- [ ] У теста есть `Assert` вообще (тест без проверки — бесполезен)
- [ ] Тестовые данные корректны
- [ ] Упал — читай stack trace сверху вниз до первой строки своего кода
