Блок Д. Найди ошибку

ИИ сгенерировал код. В каждом фрагменте — одна ошибка. Найди её, не подглядывая:

Фрагмент 1

public void EnterLogin(string login)
{
    _driver.Type(LoginField, login)
    return this;
}
Ответ

Нет ; после вызова Type(...). Код не скомпилируется.

Фрагмент 2

private const int SubmitButton = "#submit";
_driver.Click(SubmitButton);
Ответ

Тип int, а значение — строка "#submit". Должно быть string.

Фрагмент 3

public LoginPage EnterPassword(string password)
{
    _driver.Type(PasswordField, password);
}
[Fact]
public void Test() { page.EnterPassword("x").Submit(); }
Ответ

Метод объявлен с возвратом LoginPage, но return this; забыли — цепочка .Submit() после него не скомпилируется. Классическая недоработка ИИ.
