Операторы

ЗаписьЧитается какПример
=присвоитьx = 5; — «положи 5 в x»
==сравнить на равенствоif (x == 5) — «если x равен 5»
!=не равноif (x != null)
&&И (оба условия)if (a && b)
||ИЛИ (хотя бы одно)if (a || b)
!НЕ (переворот)if (!visible) — «если НЕ виден»
? :мини-ifx == 5 ? "ok" : "fail"

Null-безопасность

ЗаписьЧитается как
obj?.Prop«если obj не null — возьми Prop, иначе результат null»
a ?? b«если a не null — возьми a, иначе b»
string?«строка, которая может быть null»
x!«уверяю, тут не null» (опасно — может упасть)

Объявления

ЗаписьЧитается как
var x = ...переменная, тип понятен из правой части
List<string>список строк; в уголках — «из чего состоит»
string[]массив строк (фиксированная длина)
Task<bool>асинхронная операция, вернёт bool
const int X = 5константа — никогда не меняется
readonlyзадаётся один раз в конструкторе

Странные стрелки и скобки

ЗаписьЧитается как
x => x + 1мини-функция: «x преврати в x+1» (лямбда)
int F() => 5;метод из одной строки: { return 5; }
[Fact]атрибут-ярлык: «это тест, запусти меня»
$"текст {x}"строка с подстановкой переменных
using var x«по выходу из метода — убери за собой»
