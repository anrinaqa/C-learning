# C# Glossary

Терминология учебного пространства. Пополняется по мере прохождения уроков — термин попадает сюда, когда он понят и используется.

## Terms

**Класс (class)**:
Контейнер кода и «чертёж» для объектов. Почти весь код C# живёт внутри классов.

**Метод (method)**:
Именованный блок действий внутри класса. Вызывается как `объект.Метод(аргументы)`.

**Namespace**:
Логическая «папка» кода; обычно повторяет структуру папок проекта. Группирует связанные классы.

**Свойство (property)**:
Данные объекта с доступом `get`/`set`. Выглядит как поле: `user.Login`.

**Поле (field)**:
Переменная, объявленная внутри класса, но вне методов — «память объекта», живёт вместе с ним. Признак: нет `{ get; }`, имя часто с `_`: `_driver`.
_Отличие_: свойство видно снаружи через `get`, локальная переменная живёт только внутри метода.

**Конструктор**:
Метод, имя которого совпадает с именем класса и нет типа возврата. Запускается один раз — при `new`; раскладывает переданное по полям.

**Сигнатура**:
«Шапка» метода до `{`: видимость + тип возврата + имя + параметры. Читается как «вход → имя → выход».

**Stack trace**:
Список вызовов методов в момент ошибки. Читается сверху вниз до первой строки своего кода; `файл:line` указывает место падения.

**Assert**:
Проверка внутри теста: «ожидали X, получили Y». Тест без assert'а не проверяет ничего.

**Page Object**:
Класс, инкапсулирующий селекторы и действия над одной страницей, чтобы тесты не знали про вёрстку.
