Урок 3 · ~10 минут

Методы: вход, действие, выход

Навык: посмотреть на сигнатуру метода и сразу ответить — что принимает, что делает, что возвращает.

Сигнатура читается как предложение

public  bool        IsVisible(string selector)
   │        │            │            └ вход: параметр
   │        │            └ имя метода
   │        └ выход: тип результата
   └ кто может вызвать

Четыре вопроса к любой сигнатуре: что принимает (в скобках), что возвращает (тип перед именем), как зовут (подсказывает, что делает), кто видит (public/private).

Вход: параметры

_driver.Type(LoginField, login);   // два аргумента — куда писать, что писать

// объявление:
public void Type(string selector, string text)

Аргументы идут строго по порядку параметров. Но бывают именованные — с именем и двоеточием, тогда порядок не важен:

WaitForElement(timeout: 5000, selector: "#btn");

В тестовом коде такое сплошь и рядом — так ИИ пишет читаемые вызовы.

Выход: return и void

public void Type(...)      // void — «делаю, но ничего не отдаю»
public bool IsVisible(...) // отдаёт true/false
public LoginPage Open()    // отдаёт объект страницы (помнишь return this?)

return — то, что метод отдаёт обратно. После return метод завершается — всё ниже не выполнится.

Короткая форма: =>

public bool IsVisible(string s) => _visibleElements.Contains(s);

// то же самое длинно:
public bool IsVisible(string s) { return _visibleElements.Contains(s); }

=> у метода = «метод из одной строки, верни выражение справа».

Практика (3 минуты)

Открой FakeDriver.cs и для каждого метода ответь на 4 вопроса (вход / выход / имя / видимость):

  1. GoTo
  2. IsVisible
  3. GetText
Показать ответы
  1. Вход: строка url · Выход: void · Имя: «перейти по адресу» · public
  2. Вход: селектор · Выход: bool (виден ли элемент) · public
  3. Вход: селектор · Выход: string? — строка или null, если поля нет · public

Проверь себя

public void Click(string selector) — что возвращает метод?

  • ничего — void значит «без результата»
  • строку selector, которую принял на вход
  • результат клика — true или false

page.EnterPassword("qwerty123") — что такое "qwerty123"?

  • параметр метода
  • аргумент вызова
  • возвращаемое значение

Что делает return внутри метода?

  • печатает результат в консоль
  • отдаёт значение и завершает метод
  • сохраняет значение в поле класса

public bool IsOnDashboard() => _driver.CurrentUrl == "/dashboard"; — эквивалентно чему?

  • { _driver.CurrentUrl = "/dashboard"; }
  • { return _driver.CurrentUrl == "/dashboard"; }
  • { if (..) return true; else return false; }

Твой выигрыш

Любой вызов в тесте — page.Submit(), Assert.Equal(x, y), driver.FindElement(...) — теперь раскладывается на «кому посылаем → что передаём → что получаем».
