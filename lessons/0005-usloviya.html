Условия и логика

Навык: читать if / else ветвления и составные условия — «если элемент виден И код 200, то…»

Базовый if / else

if (statusCode == 200)
{
    // выполнится, когда условие true
}
else if (statusCode == 404)
{
    // иначе проверим это
}
else
{
    // всё остальное — «иначе»
}

В твоём FakeDriver.cs это уже есть — метод Click:

if (ok)
    CurrentUrl = "/dashboard";     // креды верные → дашборд
else
    _visibleElements.Add(".error-message");   // иначе → ошибка

Без фигурных скобок if берёт только одну следующую строку — работает, но на ревью лучше видеть скобки: меньше шанс ошибки.

Сравнения: == против =

ЗаписьЧто делает
x = 5присвоить (положить 5 в x)
x == 5сравнить (x равен 5?)
x != 5x НЕ равен 5?
> < >= <=больше / меньше, для чисел

Баг-классика: if (x = 5) — присваивание вместо сравнения. В C# компилятор обычно это не пропустит, но в `if (flag = true)` — пропустит, и условие станет всегда истинным.

Логические операторы

ЗаписьЧитаетсяКогда true
a && b«И»оба условия истинны
a || b«ИЛИ»хотя бы одно истинно
!a«НЕ»a ложно
if (statusCode == 200 && pageTitle == "Dashboard")   // и то, и другое
if (statusCode == 500 || isErrorShown)               // хоть один признак ошибки
if (!isErrorShown)                                   // ошибок нет

Из твоего `Click`: login == "admin" && password == "pass123" — оба поля должны совпасть, иначе ошибка. Как твои проверки в ТК: «и логин, и пароль верные».

Тернарный оператор — мини-if

string result = statusCode == 200 ? "PASS" : "FAIL";
// читаем: условие ? значение-если-true : значение-если-false

switch — много веток по одному значению

switch (statusCode)
{
    case 200:  // если 200
        return "OK";
    case 404:
        return "Not Found";
    default:   // всё остальное, как else
        return "Другое";
}

Практика (2 минуты)

В FakeDriver.cs, метод Click (строки 40–52):

  1. Найди оба if. Какое условие у каждого?
  2. Что должно случиться, чтобы выполнился else из строки 49?
  3. Вырази условие на строке 44 словами-«И»/«ИЛИ».
Показать ответы
  1. if (selector == "#submit") — кликнули именно кнопку отправки; if (ok) — креды верные
  2. Когда ok == false: логин ≠ "admin" ИЛИ пароль ≠ "pass123" (или оба)
  3. «логин равен admin И пароль равен pass123» — оператор &&

Проверь себя

if (statusCode = 200) — что не так?

  • всё верно — так и проверяют равенство
  • один = это присваивание; сравнение — ==
  • нельзя сравнивать переменную с числом 200

if (code == 200 && title == "Home") — когда сработает?

  • только когда И код 200, И заголовок "Home"
  • когда код 200 ИЛИ заголовок равен "Home"
  • когда код не 200 И заголовок не "Home"

if (!isErrorShown) — что проверяет?

  • что ошибка показана на странице
  • что ошибка НЕ показана
  • что переменной isErrorShown не существует

var r = ok ? "PASS" : "FAIL"; — что будет в r, если ok == false?

  • "PASS"
  • "FAIL"
  • ошибка компиляции

Твой выигрыш

Условия — мостик к проверкам. Assert.True(x == y) — это тот же if, упакованный в тест: «если условие ложно — тест красный».
