Урок 1 · ~10 минут

Анатомия файла C#

Навык: открыть любой .cs файл и за 10 секунд увидеть его скелет.

Четыре слоя каждого файла

Код C# всегда собран одинаково, как матрёшка — из внешних слоёв к внутренним:

using OpenQA.Selenium;        // 1. «подключаю библиотеку Selenium»

namespace MyTests.Pages;      // 2. «логическая папка» файла

public class LoginPage        // 3. класс — контейнер для кода
{
    public void EnterLogin()   // 4. метод — именованный блок действий
    {
        driver.Type("#login");  // команда — всегда заканчивается ;
    }
}

Когда открываешь незнакомый файл, не читай его подряд — сначала найди глазами эти четыре слоя. using скажет, с чем файл работает (Selenium? база данных? HTTP?), а имена класса и методов — что он делает.

Три знака препинания, которые правят всем

ЗнакЧто означает
;конец команды. Нет точки с запятой — код не скомпилируется
{ }границы блока. Всегда пара: открыла — закрыла. Вложенность видна по отступам
.«возьми то, что внутри»: driver.Type(...) — у объекта driver вызвали метод Type

Практика (2 минуты)

Открой файл TestExample/Pages/LoginPage.cs и найди в нём:

  1. строку namespace — в какой «папке» живёт класс?
  2. селекторы LoginField, SubmitButton — почему они вынесены наверх?
  3. все пары { } метода Submit()
Показать ответы
  1. TestExample.Pages — повторяет структуру папок проекта
  2. Чтобы при изменении вёрстки править одно место, а не весь файл
  3. Две пары: скобки тела метода Submit() и скобки класса снаружи

Проверь себя

Что означает строка using OpenQA.Selenium;?

  • файл создаёт объект браузера
  • файл подключает библиотеку Selenium
  • файл объявляет класс Selenium

Чем заканчивается тело метода?

  • точкой с запятой ;
  • закрывающей скобкой }
  • концом файла EOF

В коде page.EnterLogin("admin") что означает точка?

  • присваивание значения "admin" объекту page
  • у объекта page вызывается метод EnterLogin
  • соединение двух частей строки в одну длинную

Какая строка НЕ скомпилируется?

  • int count = 5
  • int count = 5;
  • // int count = 5

Твой выигрыш

Теперь любой файл C# — не «стена текста», а конструктор из четырёх слоёв. Этот приём работает и на файлах по 300 строк: сначала слои, потом детали.

Проверь себя на живом коде: в терминале выполни cd LearningCSharp, затем dotnet run и выбери урок 1. (В PowerShell нельзя склеивать команды через && — пиши их по одной.) Рекомендуемый первоисточник: «Тур по C#» на Microsoft Learn (раздел «Структура программы»).
