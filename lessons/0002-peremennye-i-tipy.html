Переменные и типы

Навык: прочитать любую строку тип имя = значение; и понять, что в ней лежит.

Переменная = именованная коробка

Каждая строка объявления читается слева направо:

   тип     имя       значение
    │       │            │
  string  userName = "admin";

Тип в C# фиксируется навсегда: в коробку int нельзя позже положить строку. Это первая защита от ошибок — компилятор отловит путаницу ещё до запуска теста.

Пять типов, которые закрывают 95% кода

ТипЧто хранитКак пишется значение
stringтекст"admin" — двойные кавычки
intцелые числа42, -1
doubleдробные числа19.99
boolистина/ложьtrue или false — без кавычек!
charодин символ'A' — одинарные кавычки

Классическая ошибка: "true" — это строка из четырёх букв, а не bool. bool ok = "true"; — не скомпилируется.

Три модификатора из урока с LoginPage

Вспомни строки из LoginPage.cs — теперь их можно прочитать полностью:

private const string LoginField = "#login";   // видно внутри класса, не меняется никогда
private readonly FakeDriver _driver;          // видно внутри класса, задаётся 1 раз в конструкторе
var page = new LoginPage(driver);             // var — «тип понятен из правой части»
  • const — константа: значение зашито навсегда
  • readonly — можно задать один раз, в конструкторе
  • var — не «без типа», а «компилятор, выведи сам»: var x = 5; — это int

null — «ничего нет»

Особое значение: коробка пустая. string? name = null; — вопросительный знак честно предупреждает «тут может быть пусто».

Почему это важно тебе: NullReferenceException — самая частая причина падения автотестов. Элемент не нашёлся → вернулся null → код обратился к нему → падение.

Строки с подстановкой

int timeout = 30;
string msg = $"Таймаут {timeout} сек";   // $ разрешает {переменные} внутри текста

Проверь себя

Что означает var timeout = 30;?

  • переменная может хранить любые типы данных
  • переменная типа int, компилятор вывел тип сам
  • переменная без типа, тип определится при работе

Какая строка НЕ скомпилируется?

  • bool ok = true;
  • bool ok = "true";
  • int ok = 1;

Чем const отличается от readonly?

  • ничем, это просто синонимы в языке C#
  • const задан навсегда, readonly задаётся в конструкторе
  • const для чисел, readonly для строк и объектов

Тест упал с NullReferenceException. Что это значит?

  • код обратился к переменной, в которой null
  • код сравнил два значения, и они не совпали
  • код не смог найти переменную по её имени

Твой выигрыш

Теперь строки вида private const string SubmitButton = "#submit"; читаются полностью: видимость + изменяемость + тип + имя + значение. Это 80% всех объявлений в тестовом проекте.
